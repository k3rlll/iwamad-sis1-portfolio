## About This Project
This repository contains my personal portfolio website created for the Foundational Web Interface Development course. The project is built entirely with HTML5, CSS3, and vanilla JavaScript without the use of any external frameworks. It serves as a showcase of my recent academic projects and demonstrates my ability to implement responsive layouts, semantic HTML, and custom interactivity.

## Design Decisions
1. Layout Strategy: I chose a mobile-first single-column layout that specifically transitions into a three-column grid at 1200px to ensure the projects are readable on phones while utilizing the full width of desktop screens without horizontal scrolling.
2. Color Palette: I implemented a styling system using a distinct blue primary color alongside neutral backgrounds, which provides a consistent visual rhythm and maintains clear contrast across both the light and dark themes.
3. Mobile Navigation: After testing the layout on a 375px screen width, I decided to hide them instead of keeping them horizontal/vertica;, which prevents content overflow and makes the interactive touch targets much easier to access.
